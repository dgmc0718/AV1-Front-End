- O projeto se trata de uma versão simplificada do que seria um protótipo inicial de um site
de uma fauladade.
- Eu usei o nome, dados e referência da UNIPÊ como forma de estabelecer um exemplo real do que
o site está se baseando
- As páginas disponíveis são: Uma página incial que o objetivo principal é mostrar ao usuário
a existências das outras páginas(além de também estar contendo uma vídeo de publicidade e o áudio do vídeo); Uma página para cadastro e outra para login, ambas seguindo a estrutura universal de elementos comumente presentes nesse tipo de página; Uma página que tem como objetivo incial, apenas mostrar ao usuário quais são os cursos disponíveis; e por último, uma página que contém alguns dos meios de comunição com a faculdade para fins de suporte.
